# 俄罗斯方块游戏

一个使用纯HTML、CSS和JavaScript开发的经典俄罗斯方块游戏。

## 功能特点

- 🎮 经典俄罗斯方块玩法
- 🎨 精美的现代化UI设计
- 📊 实时分数、等级和行数统计
- 🔄 方块预览功能
- ⌨️ 流畅的键盘操控
- 📱 响应式设计，支持移动端
- 🎯 难度递增系统

## 如何运行

### 方法一：直接打开（推荐）

直接双击打开 `index.html` 文件即可在浏览器中运行游戏。

### 方法二：使用本地服务器

如果您的系统安装了Python，可以在项目目录下运行：

```bash
# Python 3
python -m http.server 8000

# 或者
py -m http.server 8000
```

如果安装了Node.js，可以使用http-server：

```bash
# 首先安装http-server（如果未安装）
npm install -g http-server

# 运行服务器
http-server -p 8000
```

然后在浏览器中访问 `http://localhost:8000`

## 操作说明

- **← →** : 左右移动方块
- **↓** : 快速下落
- **↑ / 空格** : 旋转方块
- **P** : 暂停/继续游戏
- **开始游戏** : 点击按钮开始新游戏
- **暂停** : 点击按钮暂停/继续游戏
- **重新开始** : 点击按钮重新开始游戏

## 游戏规则

1. 使用方向键控制下落的方块
2. 填满一行即可消除该行并获得分数
3. 同时消除多行可获得更高分数：
   - 1行：100分 × 等级
   - 2行：300分 × 等级
   - 3行：500分 × 等级
   - 4行：800分 × 等级
4. 每消除10行提升一个等级
5. 等级越高，方块下落速度越快
6. 方块堆到顶部时游戏结束
