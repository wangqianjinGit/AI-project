# API 访问指南与常见错误解决

## 避免"Failed to fetch"错误的方法

### 正确的访问方式

**重要：** 为了确保API调用正常工作，您必须通过HTTP服务器访问应用，而不是直接双击HTML文件（即通过file://协议访问）。

1. **启动服务器**（已在运行）：
   ```bash
   cd companion
   node server.js
   ```
   服务器将在 http://localhost:8000/ 启动

2. **通过浏览器访问**：
   打开浏览器，输入以下地址：
   ```
   http://localhost:8000/login.html
   ```

### 常见错误原因与解决方法

| 错误症状 | 可能原因 | 解决方法 |
|---------|---------|---------|
| "Failed to fetch" | 服务器未启动 | 确保已运行 `node server.js` 启动服务器 |
| "Failed to fetch" | 直接通过file://协议访问HTML文件 | 按照上述说明，通过 http://localhost:8000/ 访问 |
| "无法连接到服务器" | 服务器端口被占用或防火墙阻止 | 尝试关闭占用8000端口的程序，或修改server.js中的端口号 |
| "服务器返回的不是有效的JSON数据" | 服务器端错误或响应格式问题 | 检查服务器日志，确认服务器正常运行 |

## 技术修改说明

为解决API调用问题，我们对代码进行了以下修改：

1. **添加了API基础URL生成函数**：
   - 自动检测当前页面的协议和主机
   - 处理file://协议的特殊情况
   - 确保使用正确的端口号

2. **增强了fetch请求配置**：
   - 使用完整的URL路径替代相对路径
   - 添加credentials: 'include'确保包含凭证
   - 增加内容类型检查，确保返回有效JSON数据

3. **改进了错误处理**：
   - 提供更具体、易懂的错误消息
   - 针对常见错误类型提供更清晰的提示

## 验证方法

要验证API是否正常工作，可以在服务器运行时使用以下方法：

1. **检查服务器状态**：
   查看服务器控制台输出，确认显示 "Server running at http://localhost:8000/"

2. **测试获取昵称API**：
   使用浏览器访问 http://localhost:8000/api/user/nickname 
   应该返回类似 {"nickname":"TestUser"} 的JSON响应

如果您遵循上述指南仍然遇到问题，请检查服务器日志以获取更详细的错误信息。
